# Обзор

PHMGen™ — это консольное приложение для процедурной генерации реалистичных карт высот (heightmaps). Программа использует комплексный подход, моделируя геологические процессы: тектонику плит, эрозию, седиментацию и другие явления для создания правдоподобного рельефа.

Карты высот, создаваемые программой, подходят для использования в игровых движках (Unreal Engine, Unity), 3D-редакторах и системах визуализации ландшафта. 
Программа дает возможность генерировать как карты локальных террейнов, так и целых миров - есть система симуляции тектонических плит и континентов.

---

## Основные возможности

- **Многоэтапная генерация** с возможностью включения/отключения каждого этапа
- **Симуляция тектоники плит** с конвергентными, дивергентными и трансформными границами
- **Термальная и гидравлическая эрозия** для реалистичных рек и склонов
- **Пакетная генерация** нескольких карт за один запуск
- **Экспорт в 8-bit и 16-bit PNG**
- **Многопоточность** для ускорения вычислений
- **Гибкая настройка** через конфигурационный файл
- **Локализация** (русский/английский)
- **Воспроизводимость** благодаря зерну генерации (сид)

## Быстрый старт

1. Запустите программу `PHMGen.exe`
2. При первом запуске выберите язык конфигурационного файла (1 — русский, 2 — английский)
3. Выберите разрешение карты (1-5, от 512 до 8192)
4. Укажите, использовать ли нечётное разрешение (Y/N)
5. Выберите формат экспорта (1 — 8-bit, 2 — 16-bit PNG)
6. Введите количество карт для генерации
7. Дождитесь завершения процесса
8. Сгенерированная карта высот будет лежать в папке с программой

Каждый этап можно включить или отключить через конфигурационный файл.

## Зерно (Сид)
Зерно генерации, `seed` - он же основной идентификатор генерации. Используя один и тот же сид при одних
и тех же параметрах можно воспроизводить результат генерации. 
**Особенности**
Зерно генерации имеет две основных особенности: 
 - Генерация случайного сида: для этого установите значение `seed = -1`
 - Схожесть карт при пакетной генерации: если вы используете возможность пакетной генерации (несколько сразу) карт, то их сиды будут примерно одинаковы и карта будет выглядеть плюс-минус одинаково.

# Детальное описание алгоритмов

## 1. Симуляция тектоники плит

Алгоритм моделирует движение литосферных плит и формирование рельефа на их границах.

**Этапы работы:**

```
1. Генерация N плит со случайными центрами
2. Назначение направления и скорости движения каждой плите
3. Построение диаграммы Вороного (определение принадлежности точек)
4. Определение типов границ:
   • Конвергентные (столкновение) → горы
   • Дивергентные (расхождение) → рифты, впадины
   • Трансформные (сдвиг) → небольшие хребты
5. Распространение влияния границ вглубь плит
6. Гауссово сглаживание для удаления артефактов
```

**Формула расчёта давления на границе:**

```
normalPressure = (v₁ · n) - (v₂ · n)

где:
  v₁, v₂ — векторы скорости плит
  n — нормаль к границе
```

- Положительное давление → конвергентная граница (горы)
- Отрицательное давление → дивергентная граница (рифты)
- Около нуля → трансформная граница

Добавляет геологические формации трёх типов:

| Тип | Вероятность | Формула влияния | Описание |
|-----|-------------|-----------------|----------|
| Вулкан | 50% | `exp(-t² × 2) × strength` | Конусообразное поднятие |
| Кратер | 30% | Центр: `-exp(-t² × 3) × 0.5`<br>Края: `+exp(-(t-0.8)² × 10) × 0.3` | Впадина с приподнятыми краями |
| Плато | 20% | `smoothstep` с резкими краями | Плоская возвышенность |

Где `t = distance / radius` — нормализованное расстояние от центра объекта.

# Форматы вывода

## 8-bit PNG (Grayscale)

- **Диапазон значений:** 0–255
- **Размер файла:** ~1 байт на пиксель (+ сжатие)
- **Применение:** превью, игры с низкими требованиями
- **Имя файла:** `map_N_8bit.png`

## 16-bit PNG (Grayscale)

- **Диапазон значений:** 0–65535
- **Размер файла:** ~2 байта на пиксель (+ сжатие)
- **Порядок байтов:** Big-endian (требование PNG)
- **Применение:** профессиональное использование (Unreal Engine, Unity Terrain, 3ds Max, Blender, Cinema4D, World Machine etc.)
- **Имя файла:** `map_N_16bit.png`

> **Рекомендация:** Для игровых движков используйте 16-bit формат — он обеспечивает плавные переходы высот без видимых "ступенек".

# Рекомендации

## Многопоточность

Программа автоматически использует все доступные ядра CPU.

```cpp
unsigned int numThreads = std::thread::hardware_concurrency();
```

Каждый этап разбивается на горизонтальные полосы, которые обрабатываются параллельно.

## Производительность

Программа написана на современной архитектуре и с использованием оптимизированных методов и новейших математических алгоритмов, использует мало памяти и распараллеливает вычисления, 
везде, где это возможно.

## Рекомендации по оптимизации для слабых ПК

1. **Уменьшите `erosion_iterations`** — это самый ресурсоёмкий этап
2. **Отключите ненужные этапы** — например, `enable_sedimentation=0`
3. **Уменьшите `boundary_influence_radius`** — ускорит тектонику
4. **Используйте меньшее разрешение** для тестов

# Обновление 1.1: Умная конфигурация и процедурные реки

В версии 1.1 основной упор сделан на удобство использования (UX) и расширение биологической/гидрологической достоверности рельефа.  

## 0. Пост-обработка выходной карты с вводом параметра
 - Корректировка итоговой яркости (мягкая)
 - Корректировка финального Гауссова размытия
 
## 1. Динамическое управление конфигурацией
Система работы с `config.txt` была полностью переработана:
- **Автоматическое восстановление**: Если в файле отсутствуют новые параметры, программа сама допишет их, не сбрасывая ваши старые настройки.
- **Hot Reload (Горячая перезагрузка)**: Программа отслеживает изменения в файле конфигурации. Если вы изменили `config.txt` во время работы, PHMGen™ предложит:
  1. Применить новые настройки немедленно.
  2. Продолжить со старыми.
  3. Отменить генерацию[cite: 58, 63].
- **Контроль изменений**: Перед перезагрузкой программа выведет список конкретных параметров, которые были изменены, и их старые/новые значения.

## 2. Новый этап: Генерация рек (Spline Rivers)
Помимо гидравлической эрозии, добавлен этап создания крупных речных систем на основе сплайнов.
- **`enable_rivers`**: Включение/выключение этапа.
- **`river_count`**: Количество основных речных бассейнов.
- **`river_meander`**: Коэффициент извилистости (от 0 до 1).
- **`river_delta_chance` & `river_delta_branches`**: Позволяет создавать сложные речные дельты при впадении в океан.
- **`river_oxbow_chance`**: Шанс появления стариц (затонов) в руслах.

## 3. Расширенные параметры тектоники и масок
Добавлены тонкие настройки для более точного контроля формы континентов:
- **`tectonic_boundary_strength`**: Управляет высотой горных хребтов на стыках плит.
- **`continent_transition`**: Настройка ширины береговой линии (плавность перехода).
- **`continent_sea_depth`**: Глобальный множитель глубины океанского дна.
- **`continent_land_boost`**: Дополнительный подъем всей суши относительно уровня моря.
